# core-lib-react

a base dos meus projetos react.

### o que tem aqui?
foco em arquitetura limpa. cansei de ver lógica de requisição colada na ui, então separei as responsabilidades aqui.

* `usedatafetcher`: hook para gerenciar requisições sem acoplar lógica na view.
* `httpreq`: utilitário centralizado para chamadas de api.
* mais por vir...

### por que?
para não ter que reinventar a roda ou ficar caçando no stack overflow toda vez, ou torrando tokens pedindo pro claude gerar. código meu, testado e do jeito que eu gosto de trabalhar.

### como usar
copia o que precisar. não tem mágica.
